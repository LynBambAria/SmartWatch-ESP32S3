# SmartWatch-ESP32S3
本项目采用ESP32-S3-WROOM-1-R18N8主控，MAX30102作为心率传感器，ADXL345作为三轴加速度传感器，制成一块智能手表



屏幕使用的是鱼鹰广电的1.69TFT屏幕，分辨率240*280

| 显示SPI |        8        |    D/C     |   GPIO9    |                     |
|         |        9        |     CS     |   GPIO10   |                     |
|         |       10        |    SCL     |   GPIO11   |                     |
|         |       11        |    SDA     |   GPIO12   |                     |
|         |       12        |   RESET    |   GPIO13   |                     |
|         |                 |            |            |                     |
| 触控I2C |       14        |   TP_SCL   |   GPIO4    |                     |
|         |       15        |   TP_SDA   |   GPIO5    |                     |
|         |       16        |   TP_RST   |   GPIO6    |                     |
|         |       17        |   TP_INT   |   GPIO7    |                     |

|         | 2、6、7、13、19 |    GND     |            |                     |
